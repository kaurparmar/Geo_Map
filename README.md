Geo Map Reference Website 🌍

A web-based platform that provides interactive maps and geographical references for users. The project allows users to explore locations, view geographical data, and access map-based information quickly.

🔹 Features

Interactive Map: Users can zoom and pan.

Location Search: Find any location by entering the name or coordinates.

Responsive Design: Optimized for desktop and mobile devices.

Geographical Information: Provides detailed info for selected locations.

Shortest Route finding: You can find shortest routes between any two given place.

Live Location: Can tell current location

🔹 Technologies Used

Frontend: HTML, CSS, JavaScript

Mapping Library: Leaflet.js 

Backend : PHP


🔹 Usage

Open the website directly in your browser via GitHub 

Use the search bar to find any location.
